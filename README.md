# Mi zapatera

App para llevar el registro de qué zapatos usas cada día.

## Actualizar la app

La app funciona sin internet porque guarda una copia de sí misma en el celular. Si cambias algún archivo, abre `sw.js` y sube el número de `VERSION` (por ejemplo, de `zapatera-v1` a `zapatera-v2`). La próxima vez que abras la app con internet, descargará la versión nueva. Tus datos no se tocan.
